# TodayBlock

一个安静的 Windows 桌面工作助手：右上角悬浮今日数量，点开是工作日历；把文件拖进来，让 AI 拆成任务。

> 当前版本是 **可运行的个人 MVP**，不是完整商业产品。数据默认只在本机。

## 已经实现

- 悬浮块和日历面板是两个独立窗口：关闭面板后悬浮块继续显示
- 右上角常驻悬浮块，显示「今天到期且未完成」数量；逾期用红色角标单独提示
- 按数量分级：0 / 1–2 / 3–5 / 6+，颜色、边框、轻微呼吸动效
- 点击展开 450×680 日历面板，再点收起
- 月历日期格内只画一条未完成横线，旁边显示未完成数量；全部完成显示绿色对勾
- 选中日期下方显示任务列表，可完成、编辑、删除
- 任务状态支持「待处理 / 进行中 / 已完成」
- 面板右上角「全览」打开独立工作看板，三列展示所有任务，可拖动改状态
- 任务详情支持「归属项目」和「完成情况」；项目可输入，并从历史项目名中下拉选择
- 删除任务先进入回收站，可恢复、批量恢复或彻底删除
- 全览支持搜索、项目/状态/逾期筛选、批量完成/改项目/删除
- 全览支持导出当前筛选或全部任务为 CSV / Excel / JSON
- 新建任务：标题、日期、时间、优先级、备注
- 本地 JSON 持久化，每天自动备份最近 7 份
- Windows 托盘、全局快捷键 `Ctrl+Alt+T`、开机启动开关
- 通知提醒：每日 09:00 摘要、到点提醒、逾期提醒
- 拖入 PDF / DOCX / XLSX / XLS / TXT / MD 文件，提取任务草稿
- 点快速添加栏的 `✨`，粘贴一段文字，让 AI 拆成任务
- 文件/文字解析只使用 AI；没有配置 AI 时会提示先配置，不再本地降级
- AI 结果先进入预览，确认后才写入任务
- 深色 / 浅色主题、置顶开关、数据目录、备份导出

## 快速开始

### 方式一：直接运行打包版

双击：

```text
release\TodayBlock\TodayBlock.exe
```

这是便携版，不需要安装。整个 `release\TodayBlock` 文件夹可以复制到别的 Windows 电脑。

### 方式二：源码运行

双击 `启动.bat`，或者：

```powershell
# 本机已安装 Node.js 和 pnpm
pnpm install
pnpm start
```

如果 Electron 二进制没有下载成功，可手动下载并解压到 `node_modules/electron/dist`：

```text
https://npmmirror.com/mirrors/electron/45.0.0/electron-v45.0.0-win32-x64.zip
```

解压后确保存在 `node_modules/electron/dist/electron.exe`，并写入：

```text
node_modules/electron/path.txt   -> electron.exe
node_modules/electron/dist/version -> 45.0.0
```

## 数字口径

- **大数字**：今天到期、且未完成的任务数
- **红色角标**：已逾期、且未完成的任务数
- **已完成**：不进入大数字，只影响进度环
- **悬停提示**：`今日 3 项未完成 · 逾期 1 项`

这样不会把同一个逾期任务同时算进“今日”和“逾期”。

## 显示缩放

在「设置 → 外观与行为 → 界面大小」里可以选：

- **自动**：Windows 100% 时约为 115%；125% / 150% 时跟随系统，不再叠加
- **标准**：不额外放大
- **大**：额外放大到约 115%
- **特大**：额外放大到约 125%

放大倍数会受屏幕工作区限制，小屏幕不会把面板撑出屏幕。当前先提供预设，后续如有必要再加自定义比例。

## 使用

- **展开/收起**：单击悬浮块；面板右上角 `×` 或 `Esc` 收起。
- **移动**：按住收起的悬浮块拖动；展开后按住面板顶部标题栏空白处拖动。两者位置独立，拖面板不会移动气泡。
- **新建**：面板底部输入标题，选日期，回车或点 `+`。
- **完成**：点任务左侧圆圈；再点一次恢复。
- **详情**：点任务行，修改状态、日期、时间、优先级、项目、备注、完成情况。
- **全览**：面板右上角点「全览」，在看板里搜索、筛选、拖动状态或批量操作。
- **回收站**：任务详情或全览里的删除都会先进入回收站；从全览顶部「回收站」或设置 → 数据进入，可恢复或彻底删除。
- **拖文件**：把文件拖到悬浮块或面板上，等待预览，确认后写入。  
  如果鼠标显示禁止标志，请确认应用不是以「管理员身份」运行；Windows 不允许从资源管理器向管理员进程拖放文件。
- **粘贴文字**：点快速添加栏右侧的 `✨`，粘贴会议纪要/聊天记录/邮件内容，点「开始解析」，确认后写入。支持「从剪贴板粘贴」，上限 20,000 字符。
- **托盘**：显示/隐藏、展开日历、暂停提醒 1 小时、开机启动、退出。
- **快捷键**：`Ctrl+Alt+T` 展开/收起。

## AI 配置

打开「设置 → AI 文件解析 → 配置 AI」，在弹出的 AI 设置窗口中填写：

- Base URL：例如 `https://api.deepseek.com/v1`
- 模型：例如 `deepseek-chat`
- API Key：只保存在本机

点击「测试连接」验证。兼容 OpenAI Chat Completions 接口，也可以接本地 Ollama 的兼容网关。

**没有配置 key 时**：文件拖入和文字解析会提示先配置 AI，不会生成本地规则任务；快速添加和手动任务仍然可用。

**隐私**：首次使用 AI 前请确认文件内容是否可以发送给对应服务。API Key 使用 Windows `safeStorage` 加密后保存在本机；不会写进任务数据。任务、附件、备份默认在：

```text
TodayBlock\data\
```

程序目录只读或开发模式时使用：

```text
%APPDATA%\TodayBlock\
```

## 支持的文件

| 类型 | 当前 |
|---|---|
| 文字版 PDF | 支持 |
| DOCX | 支持 |
| XLSX / XLS / XLSM | 支持（自动识别表头，交给 AI） |
| TXT / MD | 支持 |
| CSV | 按文本读取（较弱） |
| 扫描版 PDF / 图片 | 暂不支持 OCR |
| PPTX / EML | 暂不支持 |

单文件上限 20MB，一次最多 5 个文件。

## 提醒的限制

- 应用没启动就不会提醒。请保持托盘常驻，或打开「开机启动」。
- Tauri/Electron 的通知在开发模式下可能显示为 Electron；安装/打包后才会显示应用名。
- 当前没有接 Windows 任务计划程序；如果电脑休眠或应用退出，重启后会补发摘要，但不会补发每一条到点提醒。

## 开发

```powershell
# 运行
pnpm start

# 生成 UI 截图到 screenshots/
pnpm screenshot

# 跑 UI 冒烟测试（使用独立测试数据目录）
pnpm smoke

# 生成便携版到 release/TodayBlock/
pnpm package
```

打包依赖需要先准备一次：

```powershell
cd build/app
pnpm install --prod --node-linker=hoisted --ignore-scripts
cd ../..
pnpm package
```

第一次打包前，还要把 Electron 运行时解压到 `.cache/electron-dist/`。`pnpm package` 会复制它、生成 `TodayBlock.exe`，并写入图标和版本信息。

> 本机如果运行在远程桌面/无 GPU 环境，启动时可能因 GPU 进程失败。当前 `main.js` 已默认软件渲染并带 `no-sandbox` 兼容开关；正常桌面环境也适用，只是动画由 CPU 渲染。

## 数据

打包版默认使用**便携数据目录**：

```text
TodayBlock\
  TodayBlock.exe
  data\
    data.json
    attachments\
    backups\
```

复制整个 `TodayBlock` 文件夹到另一台电脑，任务、项目、附件和备份会一起带走。

首次从旧版本升级时，如果程序目录下没有 `data`，会自动从 `%APPDATA%\TodayBlock` 复制 `data.json`、`attachments`、`backups`。

如果程序放在 `Program Files` 等只读目录，会自动退回：

```text
%APPDATA%\TodayBlock\
```

开发模式仍使用 `%APPDATA%\TodayBlock`，避免污染源码目录。

回收站也保存在 `data.json` 的 `trash` 字段中，会随备份和便携目录一起带走。

API Key 使用 Windows `safeStorage` 加密，换电脑后通常无法解密，需要在 AI 设置里重新输入一次；任务数据不受影响。附件路径会在启动时尝试按 `attachments` 中的同名文件修复。

不要将正在使用的 `data.json` 直接放进 OneDrive 等实时同步目录，可能损坏。需要同步时用「导出备份」。

## 当前不做

- 手机端 / 多设备同步
- 多人协作
- 重复任务、子任务、依赖
- 时间追踪 / 番茄钟
- AI 聊天 / 自动执行
- 邮件、日历双向同步
- 扫描件 OCR、PPT

## 下一步建议

1. 先连续用 7 天，看悬浮块是否真的让你更少漏任务。
2. 用 5–10 份真实文件测试 AI 抽取，统计需要改几处日期/标题。
3. 如果核心闭环成立，再加：重复任务、拖拽改期、OCR、周视图。
